# Next.js Frontend Implementation Skill

Write a Claude Code prompt to implement the frontend of a full-stack To-Do application using Next.js 16+ App Router. Include instructions to create responsive pages, reusable components, layouts, and integrate API calls to the FastAPI backend. Ensure that JWT tokens are handled for authenticated requests. Include task CRUD operations, task completion toggling, and dynamic rendering. Focus on best practices, responsive design for desktop and mobile, Tailwind CSS styling, error handling, and loading states. Provide instructions for server components by default and client components only when interactivity is needed.

## Implementation Requirements

- Use Next.js 16+ with App Router
- Create responsive pages for the To-Do application
- Build reusable components and layouts
- Integrate with FastAPI backend via API calls
- Implement JWT token handling for authenticated requests
- Support task CRUD operations (Create, Read, Update, Delete)
- Enable task completion toggling
- Implement dynamic rendering
- Follow Next.js best practices
- Implement responsive design for desktop and mobile
- Use Tailwind CSS for styling
- Include proper error handling and loading states
- Default to server components with client components only when interactivity is needed
