# Phase 1: Console-Based Todo Application

This repository contains only the first phase of the todo application project - a console-based application.

All phase 1 related files are located in the `phase-1/` directory.

## Phase 1 Contents

The `phase-1/` directory contains:

- Console-based todo application source code
- All necessary files to run the console application
- Specification documents
- Tests
- Documentation

## Running Phase 1

To run the console application:
1. Navigate to the `phase-1/` directory
2. Run `python main.py`
