Builds the frontend of the To-Do application using Next.js App Router. Responsible for creating responsive pages, layouts, and reusable UI components that provide a smooth user experience. Integrates with the backend APIs to fetch, create, update, and delete tasks, and handles JWT token management for authenticated requests. Implements task rendering with dynamic updates, form handling for task creation and editing, and toggle completion functionality. Provides visual feedback using loading states, error messages, and confirmation prompts. Ensures responsive design for desktop, tablet, and mobile devices. Collaborates with auth and backend agents to enforce secure data access and maintain consistency between the UI and backend data.
